《不卡带 (Unwind)》隐私政策与个人信息保护声明

应用名称：不卡带 (Unwind) 应用包名：com.beckmint.unwind 版本号：v0.6.6 及以上 生效日期：2026年10月21日 更新日期：2026年10月21日
【核心声明】 欢迎您使用由开发者 BeckMint 独立设计并开发的本地音乐播放工具「不卡带 (Unwind)」（以下简称“本应用”或“我们”）。我们严格奉行“数据最小化”与“纯净本地离线运行”原则，不收集任何用户身份信息、不读取设备硬件识别码、未集成任何第三方商业广告与追踪 SDK。请您在安装并使用本应用前仔细阅读本隐私政策。

一、我们如何收集与使用您的信息

作为一款以拟物复古随身听为核心特色的本地音乐播放器，本应用的核心功能均在您的手机本地设备中独立执行：

  • 不收集个人身份信息：本应用不设用户注册或登录功能，不收集您的姓名、身份证号、手机号码、电子邮件、银行账号、通讯录、短信等任何个人隐私身份数据。
  • 不收集设备硬件标识符：本应用不读取设备的 IMEI、IMSI、MAC 地址、Android ID、OAID、ICCID 等任何能够唯一标识您个人或设备的敏感硬件标识码。
  • 不获取位置信息：本应用不申请 GPS 定位权限，不收集您的精确或粗略地理位置信息。
  • 纯本地偏好存储：您在应用内的本地播放列表、主题配色偏好、上次播放进度及 EQ 状态，均通过 Android 原生 DataStore 组件加密存储在您手机本地的应用私有沙盒中。卸载应用或在系统设置中“清除存储数据”将立即且彻底销毁所有本地偏好数据。

三、第三方 SDK 目录与数据共享披露

【零第三方追踪承诺】
本应用承诺：当前版本未集成任何第三方商业广告 SDK、未集成任何用户行为统计/分析 SDK、未集成任何第三方消息推送 SDK 或行为追踪组件。
我们绝不会向任何第三方公司、组织或个人出售、出租、共享或转让您的任何数据或媒体信息。

四、用户如何管理权限与数据

您对您的设备权限与本地数据拥有完全的控制权：

  1. 撤回系统授权：您可以随时通过手机系统设置随时变更或撤回权限授权（路径：系统【设置】 > 【应用与权限】 > 【应用管理】 > 【不卡带】 > 【权限】）。撤回读取媒体文件权限后，应用将无法读取本地音乐播放，但不影响手机其他功能的正常运行。
  2. 彻底清除数据：您可以在上述系统应用管理界面中选择“清除数据”或直接卸载本应用，应用沙盒内存储的所有播放列表和个性化设置将被一次性完全彻底销毁。

五、未成年人隐私特别保护

本应用是一款单纯的离线音乐播放工具，不包含任何账户注册、社交互动、算法内容推荐或网络交易功能。若您是未满 18 周岁的未成年人，建议您在监护人的指导下阅读本隐私政策并使用本应用。我们不会主动收集未成年人的任何个人信息。

六、隐私政策的修订与变更

随着本应用功能的迭代升级或相关法律法规的要求，我们可能会适时修订本隐私政策的内容。修改后的隐私政策将在应用版本更新时随附更新，并在公开发布渠道（包括 GitHub 官方合规主页）进行公示。若涉及核心业务权限或数据处理方式的重大变更，我们将在应用启动或显著位置予以提示。
