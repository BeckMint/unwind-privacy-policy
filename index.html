《不卡带 (Unwind)》隐私政策与个人信息保护声明

应用包名：com.beckmint.unwind 适用版本：v0.6.9 及以上 更新日期：2026年10月22日 生效日期：2026年10月22日
【核心合规声明与零权限冷启动保障】
「不卡带 (Unwind)」是一款专为小折叠外屏及通用 Android 设备打造的纯本地拟物复古随身听。我们秉承“最小必要”与“纯净本地离线运行”原则：
1. 零权限纯净冷启动：首次安装启动并同意本隐私政策后，本应用绝不主动向系统申请任何媒体或存储权限。应用内置高保真离线音乐，未授予任何敏感权限亦可完整畅听与操控；
2. 按需申请与前置目的明示：严格遵循工信部 164 号文及主流应用商店隐私规范，仅在您主动点击「OPEN 出仓」选歌或导入本地视频时，在调起系统权限前通过前置说明弹窗明确告知权限用途，经您确认后才调起系统授权；若您暂不授权，关闭弹窗即可继续使用内置音乐，绝不强行索权；
3. 零隐私收集与零第三方追踪：应用无用户账号体系，不采集设备识别码（IMEI、MAC、OAID 等），未集成任何第三方商业广告 SDK、行为统计 SDK 或推送追踪组件。

一、我们如何收集与使用您的个人信息

由于本应用为 100% 本地单机随身听，在日常运行中不会主动收集、存储或上传您的任何个人信息：

  • 无账号体系：本应用无需注册、登录或绑定任何第三方账号，不收集姓名、手机号、邮箱、身份证件或任何社交账户信息。
  • 不采集设备特征码：不调用、不采集 IMEI、IMSI、MAC 地址、Android ID、OAID、ICCID、硬件序列号等敏感设备识别信息。
  • 不收集位置与通信记录：不申请地理位置权限，不访问通讯录、短信、通话记录、日历或相机。
  • 完全本地沙盒运行：您的自建歌单、7 款液晶背光配置、7 档硬件 EQ 模式、上次播放进度等偏好设置，全部保存在手机本地应用私有沙盒（Android DataStore）中，绝不上报云端。

三、第三方 SDK 目录与数据共享披露

【零第三方商业追踪承诺】
本应用郑重承诺：未集成任何第三方商业广告 SDK、未集成任何用户行为统计/打点分析 SDK、未集成任何第三方消息推送 SDK 或行为追踪组件。
本应用仅使用 Google 官方开源核心库（Jetpack Compose 视图层、Media3/ExoPlayer 本地音频解码引擎、Coil-kt 本地图片加载器），上述基础库均在纯本地沙盒离线运行；
我们绝不存在向任何第三方公司、组织或个人出售、出租、共享或转让用户个人信息的情形。

四、用户如何管理权限与数据

您对您的设备权限与本地数据拥有完全的控制权：

  1. 撤回系统授权：您可以随时通过手机系统设置查阅、变更或撤回权限授权（路径：系统【设置】 > 【应用与权限】 > 【应用管理】 > 【不卡带】 > 【权限】）。撤回读取媒体文件权限后，应用将无法读取本地音乐，但您仍可正常使用内置音乐畅听与全部随身听操作。
  2. 彻底清除数据：您可以在上述系统应用管理界面中选择“清除数据/存储”或直接卸载本应用，应用沙盒内存储的所有播放列表和个性化设置将被一次性完全彻底销毁。

五、未成年人隐私特别保护

本应用是一款单纯的离线音乐播放工具，不包含任何账户注册、社交互动、算法内容推荐或网络交易功能。若您是未满 18 周岁的未成年人，建议您在监护人的指导下阅读本隐私政策并使用本应用。我们不会主动收集未成年人的任何个人信息。

六、隐私政策的修订与变更

随着本应用功能的迭代升级或相关法律法规的要求，我们可能会适时修订本隐私政策的内容。修改后的隐私政策将在应用版本更新时随附更新，并在公开发布渠道（包括 GitHub 官方合规主页）进行公示。若涉及核心业务权限或数据处理方式的重大变更，我们将在应用启动或显著位置予以提示。
