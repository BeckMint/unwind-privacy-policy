1997 年，Winamp 凭借开放的皮肤（Skin）机制，将播放器的灵魂与视觉统治权交还给了全世界的音乐爱好者。27 年后，「不卡带 (Unwind)」将这份纯粹的硬件拟物自由带到了折叠屏时代。

👨‍💻 面向人类设计师与开发者

完全声明式的 JSON / Kotlin 属性契约，支持对点阵高亮色、鬼影像素色、拉丝机体底盘、微倒角琴键按键以及实体镜头旋钮光圈进行全维度定制。

🤖 AI 提示词指南 (复制即用)

将以下提示词模板复制到 Claude, ChatGPT, Gemini 或 Cursor 中，只需将 [CONCEPT] 替换为您喜爱的硬件概念：

You are an expert industrial designer specializing in retro skeuomorphic audio hardware and modern mobile design. Generate a compliant theme for the open-source "Unwind (不卡带)" retro player app based on this concept: CONCEPT: [在这里输入你的设计概念，例如: "Cyberpunk 2077 Night City", "1968 Braun Dieter Rams Minimalist", 或 "1980s Neon Synthwave Sunset"] The output must strictly conform to the Unwind Theme Specification (v1.0.0). Output format: 1. Short design summary & historical hardware inspiration (2-3 sentences). 2. JSON configuration block conforming to the schema: { "id": "theme_identifier", "name": "DISPLAY NAME", "author": "Your Name / Handle", "license": "MIT", "description": "Short summary", "screenTarget": "AUTO", "colors": { "lcdPrimary": "#...", "lcdDim": "#...", "lcdBg": "#...", "isLightBg": false, "hardwareAccent": "#..." }, "chassis": { "chassisBg": "#...", "chassisBorder": "#...", "chassisHighlight": "#...", "chassisShadow": "#..." }, "controls": { "buttonIdleTop": "#...", "buttonIdleBottom": "#...", "buttonBorder": "#...", "isWinampStyle": false } } 3. Kotlin DSL enum snippet ready to be added to RetroTheme.kt.

📋 规范参数速查表 (Theme Properties)

属性字段 类型 设计说明 推荐取值与设计法则
id String 唯一主题标识符 小写英文字母与下划线，例如 cyberpunk_neon
name String LCD 点阵屏显示名称 建议不超过 12 个大写字母，以确保在复古点阵屏中居中整齐
lcdPrimary Hex Color 点阵高亮像素、VU表活跃指示 高饱和高明度，与 lcdBg 对比度必须 > 7:1
lcdDim Hex Color 未点亮鬼影像素 (Ghost Matrix) 低对比度微光，提供真实物理液晶面板反光感
lcdBg Hex Color 点阵液晶背光腔体底色 暗色系通常为 #000000 ~ #0A100D；EL冷光通常为 #98B828
isLightBg Boolean 是否为全亮反衬背光 为 true 时系统将自动将点阵像素反相为深色墨水显示
hardwareAccent Hex Color 镜头刻度环、电位器圆弧与按键倒角 机械高光主色，通常呼应 lcdPrimary 或采用撞色设计
chassisBg Hex Color 机体外壳金属/拉丝底色 阳极氧化铝合金、锻造碳或复古米白质感
buttonIdleTop / Bottom Hex Color 3D 琴键按键上下渐变色 上高光下暗部（落差 20%~30%），营造顶置光源下的拟物立体凸起
