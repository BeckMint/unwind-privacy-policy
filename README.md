## 核心原则与郑重声明

欢迎您使用「不卡带 (Unwind)」（以下简称“本应用”或“我们”）。作为一款以拟物复古随身听为核心特色、深度适配小折叠屏手机外屏的音乐播放器，我们严格奉行**“数据最小化”**、**“零商业追踪”**与**“私有数据端到端安全掌控”**原则：

1. **本地离线优先与无网畅听**：本应用支持无网络单机畅听本地私藏曲库，默认不产生任何互联网数据传输。内置精选高保真离线试听曲目，首次安装启动并同意本隐私政策后，即使在完全未授予任何媒体权限的状态下，您仍可开箱即用，畅享磁带旋转运转、5 重声音滤镜切换、7 档硬件 EQ 音效及全部机械控制功能。
2. **飞牛私有云 (fnOS / WebDAV) 远程直连与 TEE 加密守护**：为了满足音乐发烧友对海量无损母带的跨设备串流需求，本应用新增飞牛私有云直连功能。该功能仅在您主动配置并启用时，通过网络权限与您自主指定的家用私有 NAS 设备建立点对点安全直连。**绝无第三方中转服务器**，WebDAV 访问密钥采用底层硬件安全芯片（Android Keystore TEE / StrongBox）AES-256 GCM 硬件加密存储，防逆向、不可导出。
3. **权限按需申请与前置目的明示**：严格遵循工信部信管函〔2020〕164号文及各大应用商店合规规范，仅当您主动触发需要读取本地媒体的业务功能（如点击「OPEN 出仓」选择本地音乐、点击「导入本地视频」）时，应用会在调起系统权限之前，通过前置说明浮窗（Rationale Dialog）清晰告知权限申请目的与隐私承诺。经您点击「同意并授权」后才会拉起系统权限框；若您点击「暂不授权」，浮窗立即关闭且绝不强行申请系统权限。
4. **零个人隐私收集**：本应用不设用户注册或登录系统，不收集您的姓名、身份证号、手机号、通讯录、短信、精确地理位置或银行支付凭据。
5. **零硬件设备标识码读取**：不读取 IMEI、IMSI、MAC 地址、Android ID、OAID 等任何可标识设备或个人的敏感硬件识别码。
6. **零第三方广告与推送 SDK**：当前版本未集成任何商业广告 SDK、未集成任何后台自启动或拉活推送服务；引入基础统计与 APM 性能监控组件以守护应用稳定性，严格按最小必要原则收集匿名化运行指标，绝不收集或上传您的私藏文件或个人隐私数据。

## 三、用户如何管理权限与数据

1. **撤回权限授权**：您可随时在手机系统设置（路径：系统【设置】 > 【应用与权限】 > 【应用管理】 > 【不卡带】 > 【权限】）中查阅、变更或撤回对本应用的授权。撤回读取媒体文件权限后，应用将无法读取本地音乐播放，但您仍可正常使用内置音乐畅听与全部播放器操作。
2. **清除私有云凭据与彻底销毁本地数据**：在应用内【设置 -> 飞牛私有云】中点击“断开连接并清空配置”，存储在硬件安全区（TEE）的 AES-256 加密凭证将被立即永久擦除；您亦可在系统应用管理中选择“清除数据”，应用沙盒内存储的所有播放列表和个性化设置将被一次性完全彻底销毁。

## 四、未成年人隐私特别保护

本应用是一款单纯的音乐与视频播放工具，不包含任何账户注册、社交互动、算法内容推荐或网络交易功能。若您是未满 18 周岁的未成年人，建议您在监护人的指导下阅读本隐私政策并使用本应用。我们不会主动收集未成年人的任何个人信息。
